
# 업무 인수인계서 자동화 MVP

OpenAI API 없이 동작하는 Streamlit 기반 인수인계서 자동화 프로젝트입니다.

## 주요 기능

- 표준 인수인계 항목을 웹 폼에서 입력
- 반복 행 추가/삭제
- 입력 데이터 JSON 다운로드
- 인수인계서 DOCX 자동 생성
- AI/API 없이 동작

## 실행 방법 (Windows)

### 1. 프로젝트 폴더 열기
VS Code에서 이 폴더를 엽니다.

### 2. 터미널 열기
상단 메뉴:
Terminal > New Terminal

### 3. 가상환경은 선택 사항
초보 단계에서는 생략해도 됩니다.

### 4. 필요한 패키지 설치
```bash
pip install -r requirements.txt
```

### 5. 실행
```bash
streamlit run app.py
```

브라우저가 자동으로 열립니다.
안 열리면 터미널에 표시되는 Local URL을 Ctrl+클릭하세요.

## API 없이 업무메모를 자동 분류하는 규칙

`업무메모_예시.txt`를 참고하세요.

핵심은 자유문장 전체를 AI처럼 이해하게 하는 대신,
다음과 같이 태그를 붙여 입력하는 것입니다.

```text
[업무1]
주요업무: ...
업무목적: ...
업무프로세스: ...
우선순위: ...
업무개요: ...
진행중프로젝트: ...
리스크: ...
참고파일: ...
```

표 형태 정보는 `|` 기호로 구분합니다.

```text
[긴급일정]
2026-08-31 | 보고서 제출 | 팀장 검토 후 제출 | 홍길동
```

이 형식은 `memo_parser.py`가 API 없이 구조화할 수 있습니다.

현재 `app.py`는 직접 폼 입력 → DOCX 생성까지 완성된 버전입니다.
다음 단계에서는 `memo_parser.py` 결과를 Streamlit 폼의 초기값으로 연결하면
'업무메모.txt 불러오기 → 자동 채움 → 검토 → DOCX 생성' 흐름으로 발전시킬 수 있습니다.
