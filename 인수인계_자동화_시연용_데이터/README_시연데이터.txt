# 인수인계 자동화 시연용 예시 데이터

이 폴더는 인수인계 자동화 및 문서 기반 Q&A 시연을 위해 만든 가상 데이터입니다.

## 파일 구성
1. 01_업무일정.xlsx - 날짜별 업무, 담당, 상태, 우선순위, 진행률, 다음 조치, 마감, 관련 파일
2. 02_프로젝트_진행현황.xlsx - 현장/프로젝트별 단계, 진행률, 다음 액션, 의사결정 필요사항, 리스크
3. 03_담당자_연락망.xlsx - 내부/외부 담당자, 연락수단, 관련 업무, 커뮤니케이션 유의사항
4. 04_계정_권한_자산.xlsx - 시스템/문서/자산별 인계 상태와 방법
5. 05_Q&A_테스트케이스.xlsx - 질문, 기대답변, 근거 파일/위치, 난이도, 검증포인트 25개

## 시연 포인트
- 단순 검색: 날짜, 담당자, 진행률, 마감
- 조건 검색: 긴급 업무, 50% 이상 진행 업무, 미완료 인계
- 종합 질문: 첫 주 우선순위 3개, 미해결 이슈 요약
- 파일 간 연결: 프로젝트 + 연락망, 일정 + 권한/자산
- 근거 제시: 답변과 함께 어떤 파일/행을 사용했는지 보여주기

모든 이름, 연락처, 회사/현장명은 예시용 가상 데이터입니다.
